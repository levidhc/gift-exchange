# 🎁 禮物心機猜猜樂 (Gift Guess & Swap)

專為聚會派對設計的**交換禮物互動遊戲網頁應用程式**！

---

## 📖 遊戲核心玩法

1. **參加者 ($N$ 個人)**：每個人加入遊戲後，創作一張代表自己「想要禮物」的線索圖（可用內建繪圖板手繪，或直接上傳圖片）。
2. **⚠️ 關鍵核心規則**：**「絕對不能直接畫出禮物本體！」**
   - 必須透過特徵、諧音、使用情境、謎語、聲音或誇張聯想來表達。
   - 例如：想要「吹風機」➡️ 畫狂風暴雨中濕透的小柴犬！想要「藍芽耳機」➡️ 畫雙手摀住耳朵微笑的兔子！
3. **秘密配對 (Secret Santa)**：系統自動進行完美密排演算法（保證無人抽到自己，每人抽中一位送禮對象）。
4. **三選一猜謎 (3-Image Guessing)**：
   - 每個人會看到：**「你抽到的人的名字」** 以及 **「3 張神秘畫作」**。
   - 其中只有 1 張是他真正畫的，另外 2 張是混淆障眼法！
   - 你必須發揮觀察力與默契，從 3 張圖中猜出哪一張是他畫的！
5. **揭曉心願與大狂歡**：
   - 猜完立即揭曉是否正確，並公佈他心中真正的禮物願望。
   - 最終大揭曉呈現完整交換禮物贈送鏈、心靈相通神探榜、以及所有人的靈魂畫作展覽館！

---

## 🚀 支援兩種遊玩模式

### 模式一：🌐 線上房間模式（多支手機即時連線）
- 主持人在電腦/平板上建立房間，畫面上會自動產生專屬 **4 碼房號** 與 **QR Code**。
- 朋友只要連到同一個 Wi-Fi，用手機相機掃描 QR Code 或輸入網址即可立即加入！
- 畫作與猜測結果即時透過 WebSocket 同步。

### 模式二：📱 單機輪流玩（Pass & Play 免網路同樂）
- 聚會如果只有一台 iPad 或筆電，可直接使用此模式！
- 輸入所有玩家名字後，螢幕會自動帶有隱私遮罩：「請把螢幕交給小明，其他人請轉身避嫌～」，輪流作畫與猜題，最後全場一起看大揭曉！

## 💻 本地啟動方式 (Windows)

### 方式 1：一鍵點擊啟動
直接雙擊執行目錄中的：
```
啟動遊戲.bat
```
它會自動開啟瀏覽器並啟動本地伺服器。

### 方式 2：使用命令列啟動
確保已安裝 Python 3.9+ 及套件：
```bash
pip install -r requirements.txt
python app.py
```
啟動後終端機會顯示：
- 電腦本機網址：`http://localhost:8000`
- 手機加入網址（同一Wi-Fi）：`http://192.168.x.x:8000`

## ☁️ 免費雲端線上佈署指南 (讓遠端朋友也能跨網際網路玩)

若想要直接掛在公網上，給各地的朋友隨時點連結加入，可免費佈署至以下平台：

### 佈署至 Render.com (推薦，免費)：
1. 將本專案上傳至 GitHub。
2. 登入 [Render.com](https://render.com) 點選 **New Web Service**。
3. 連結你的 GitHub 儲存庫。
4. 設定：
   - **Environment**: `Python`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python app.py`
5. 點擊 **Create Web Service**，幾秒鐘後即可獲得全球可連線的 HTTPS 專屬網址！

## 🎨 專案特色

- **純手工打造現代節慶深色 UI**：以深邃雪夜藍搭配暖金與寶石紅，支援玻璃擬態 (Glassmorphism) 與流暢微動畫。
- **Web Audio API 純程式合成音效**：內建按鈕音、畫筆音、抽籤拉霸音、答對歡呼音效與幽默答錯音效，零外掛音檔即開即聽。
- **智慧觸控繪圖板**：防止手機螢幕滾動干擾，支援 12 色調色盤、霓虹光芒筆、畫筆粗細調節、橡皮擦、Undo 復原與圖片上傳自動壓縮。
- **Canvas-Confetti 粒子慶祝特效**：結算與答對時觸發全螢幕彩帶禮花！
